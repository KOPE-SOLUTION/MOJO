# โครงการประจำหลักสูตรและ Capstone

เอกสารนี้เป็นโจทย์สำหรับสร้างในอนาคต ยังไม่มี implementation ของโครงการปลาย Phase

## โครงการที่พัฒนาต่อกัน

| ช่วง | ผลงาน | ตัวอย่างเกณฑ์สำเร็จ |
|---|---|---|
| EP.8 | Terminal Measurement Report | ข้อมูล 28, 30, 32 มีค่าเฉลี่ย 30; รายการว่างรายงาน error |
| EP.16 | Tested Analyzer | เปลี่ยนเงื่อนไข >= เป็น > แล้ว test ที่ค่าเท่ากับเกณฑ์ต้องตรวจพบ |
| EP.24 | Hybrid CSV Analyzer | Python โหลด/วาดกราฟ Mojo คำนวณ ผลตรง reference ภายใน tolerance |
| EP.32 | CPU Performance Study | เปรียบเทียบ Python loop/NumPy/Mojo ด้วยข้อมูล ชนิด และงานเดียวกัน |
| EP.40 | GPU Performance Study | เวกเตอร์ขนาดไม่เต็ม block ยังถูก รายงาน transfer และ end-to-end |
| EP.48 | Capstone | รันซ้ำจากเอกสารได้และอธิบายข้อจำกัด |

## Capstone A วิเคราะห์ข้อมูลเซนเซอร์จำลอง

ใช้ไฟล์ CSV จำลองที่มีเวลา อุปกรณ์ และค่าการวัด

กำหนดรูปแบบข้อมูลและหน่วยให้ชัดก่อนเขียนโปรแกรม

ลำดับงานหลัก:

1. ตรวจข้อมูล
2. ปรับสเกลหรือคำนวณค่าเฉลี่ยเคลื่อนที่
3. สรุปตามช่วงเวลา
4. สร้างกราฟ
5. เปรียบเทียบกับผลอ้างอิงจาก NumPy/pandas

เริ่มด้วย CPU ส่วน GPU เป็นทางเลือกเมื่อข้อมูลและฮาร์ดแวร์เหมาะสม

กรณีตรวจ: ว่าง, หนึ่งค่า, ค่าขอบเขต, NaN/Inf, timestamp ผิดลำดับ, ขนาดหน้าต่างมากกว่าข้อมูล และขนาด batch หารความกว้าง SIMD ไม่ลงตัว นโยบายค่าว่างและการเรียงเวลาต้องระบุให้ชัด

## Capstone B ประมวลผลภาพขนาดเล็ก

ใช้ภาพทดสอบที่สร้างเองและระบุ dtype/shape เลือกงานเพียงหนึ่งอย่าง เช่น threshold หรือ box blur เทียบกับ Python reference ตรวจภาพ 1×1, ขอบภาพ, ขนาดไม่เต็ม tile และค่าพิกเซลต่ำสุด/สูงสุด

## สิ่งส่งมอบร่วมกัน

- README ที่บอกวิธีสร้าง environment และรัน
- implementation และ reference ที่ให้ผลตามนิยามเดียวกัน
- test matrix พร้อมผลจริง
- raw benchmark และรายงานวิธีวัด
- รายการข้อจำกัดและสิ่งที่ยังไม่ทดสอบ
- ตัวอย่างการใช้งานและคำอธิบายผลลัพธ์

ขอบเขตเริ่มต้นเป็นข้อมูลในเครื่อง ไม่จำเป็นต้องเพิ่ม MQTT, เว็บ API หรือฐานข้อมูลเพื่อเรียน Mojo ให้จบ
