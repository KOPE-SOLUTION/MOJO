# คำศัพท์ที่ใช้ในหลักสูตร

| คำ | ความหมายสำหรับเริ่มเรียน | เริ่มที่ |
|---|---|---|
| compiler | เครื่องมือแปลและตรวจโค้ดก่อนทำงาน | EP.1 |
| entry point | จุดเริ่มของโปรแกรมที่รัน เช่น main | EP.1 |
| literal | ค่าที่เขียนตรงในโค้ด เช่น 3 หรือข้อความในคำพูด | EP.1–2 |
| static type | ชนิดข้อมูลที่ compiler กำหนดและตรวจ | EP.2 |
| type inference | compiler อนุมานชนิดโดยเราไม่เขียนชื่อชนิด | EP.2 |
| boundary | ค่าขอบเขตที่แยกพฤติกรรม เช่น เท่ากับเกณฑ์ | EP.3 |
| iteration | การทำงานหนึ่งรอบของลูป | EP.4 |
| accumulator | ตัวแปรเก็บผลสะสมระหว่างวนซ้ำ | EP.4 |
| ownership | กฎว่าใครควบคุมค่าและอายุของมัน | Phase 2 |
| lifecycle | การสร้าง ย้าย คัดลอก และทำลายค่า | Phase 2 |
| interop | การเชื่อมให้ภาษา/ระบบต่างกันทำงานร่วมกัน | Phase 3 |
| dtype | ชนิดของสมาชิกข้อมูล เช่น float32 | Phase 3 |
| benchmark | การวัดงานตามเงื่อนไขที่กำหนดเพื่อเปรียบเทียบ | Phase 4 |
| SIMD | คำสั่งเดียวประมวลผลข้อมูลหลายสมาชิก | Phase 4 |
| kernel | ฟังก์ชันงานคำนวณ; ใน Phase 5 ใช้หมายถึงงานบน GPU | Phase 4–5 |
| synchronization | ทำให้ลำดับงาน/การเข้าถึงข้อมูลตรงตามเงื่อนไขที่ต้องรอ | Phase 5 |

คำอธิบายนี้เป็นสะพานสำหรับเริ่มต้น เมื่อถึงบทจริงจะขยายเงื่อนไขและข้อจำกัดให้ครบ
