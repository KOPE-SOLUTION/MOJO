# ตรวจปัญหาระหว่างเรียน

| อาการ | ตรวจอะไร | วิธีแก้เฉพาะจุด |
|---|---|---|
| PowerShell หา mojo ไม่พบ | กำลังใช้ Windows terminal หรือไม่ | เข้า wsl -d Ubuntu-24.04 แล้ว activate environment |
| Ubuntu หา mojo ไม่พบ | อยู่ MOJO และเปิด .venv หรือยัง | source .venv/bin/activate แล้ว mojo --version |
| mojo --version ยังเป็น 1.1.0 | activate environment ที่ถูกตัวหรือยัง | ทำขั้นอัปเดต environment เดิมใน [คู่มือติดตั้ง](setup-windows-wsl.md) แล้วตรวจรุ่นอีกครั้ง |
| ไม่มี .venv | เพิ่งดาวน์โหลดหลักสูตรหรือไม่ | สร้างตาม setup-windows-wsl.md |
| ไม่พบไฟล์ main.mojo | ตำแหน่ง terminal และชื่อไฟล์ | ใช้ pwd และ ls ตรวจ อย่าเผลอบันทึก .mojo.txt |
| แก้แล้วผลเหมือนเดิม | ไฟล์ที่เปิดกับไฟล์ที่รันตรงกันหรือไม่ | บันทึกแล้วรัน path เดิมที่ระบุในบท |
| Error กล่าวถึง Print | ชื่อฟังก์ชันตัวใหญ่/เล็ก | ใช้ print ตัวเล็ก |
| ใส่ข้อความลง Int ไม่ได้ | ค่ากับชนิดตัวแปรตรงกันหรือไม่ | เปลี่ยนข้อมูลหรือออกแบบชนิดให้ตรงโจทย์ |
| รันได้แต่ค่า 30 ไม่เตือน | เงื่อนไข > หรือ >= | เทียบกับกฎภาษาไทยและทดสอบค่าเท่ากับเกณฑ์ |
| while ไม่หยุด | ตัวแปรในเงื่อนไขเปลี่ยนหรือไม่ | Ctrl+C แล้วตรวจเงื่อนไขและการอัปเดต |
| โค้ดออนไลน์ใช้ไม่ได้ | รุ่น compiler และรุ่นเอกสาร | ยึด 1.2.0 ของชุดนี้ก่อน อ่าน release notes ก่อนย้าย |
| Python library ไม่พบใน Mojo | ติดตั้งใน Windows หรือ Ubuntu | ใช้ environment เดียวกันกับ Mojo เมื่อเรียน Phase 3 |
| Import GPU ไม่พบ | API อยู่ package/รุ่นใด | ตรวจ Mojo/MAX คู่กันเมื่อถึง Phase 5 |

ถ้าติดขัด ให้เก็บคำสั่งที่รัน เวอร์ชัน Mojo โค้ดสั้นที่สุดที่ยังเกิดปัญหา และ error เต็ม หลีกเลี่ยงแก้หลายเรื่องพร้อมกัน เพราะจะไม่รู้ว่าจุดใดทำให้หาย

[กลับคู่มือติดตั้ง](setup-windows-wsl.md)
