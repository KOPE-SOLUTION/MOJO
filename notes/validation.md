# ผลตรวจชุดเริ่มต้น Mojo

ตรวจวันที่ **23 ตุลาคม 2026** เวลา 17:52–17:53 น. (Asia/Bangkok) บน Ubuntu 24.04.4 LTS ผ่าน WSL2

Compiler: **Mojo 1.2.0 (2016d0cd)** · Python ของตัวตรวจ: 3.12.3

## ผลรันจริง

**ยืนยันพฤติกรรมตามคาดครบ 34/34 กรณี** ด้วย [สคริปต์ตรวจตัวอย่าง](../scripts/check_examples.py) และ [รายการกรณี](../scripts/example-cases.json)

| กลุ่ม | จำนวน | ผล |
|---|---:|---|
| โค้ดทีละขั้น EP.1–4 | 12 | exit 0 และ stdout ตรงที่ระบุ |
| โค้ดจบบท EP.1–4 | 4 | exit 0 และ stdout ตรงที่ระบุ |
| เฉลย 2 ข้อต่อบท | 8 | exit 0 และ stdout ตรงที่ระบุ |
| กรณีจงใจผิดชื่อ/ผิดชนิด | 2 | compile ไม่ผ่าน พร้อมข้อความวินิจฉัยที่เกี่ยวข้อง |
| กรณีผิดตรรกะ >= และขอบท้าย range | 2 | รันได้และได้ผลผิดตามที่ใช้สาธิต |
| EP.3 ค่า -1, 0, 29, 30, 31, 35 | 6 | ได้สถานะตรงกฎของบท |
| รวม | 34 | ตรงความคาดหมายทุกกรณี |

คำว่า “ตรงความคาดหมาย” ในกรณีจงใจผิดหมายถึงตรวจพบพฤติกรรมที่ต้องการใช้สอน ไม่ได้หมายความว่าโค้ดผิดนั้นควรนำไปใช้เป็นคำตอบที่ถูก

ข้อมูล stdout, stderr, exit code, รุ่น Python, ระบบ และเวลาเริ่ม/จบแบบ UTC อยู่ใน [ผลรันดิบ](validation-results.json) รันทดสอบด้วย .venv หลักของหลักสูตร หลังตรวจ dependency ด้วย pip check แล้วไม่พบปัญหา

กรณีที่คาดให้รันสำเร็จทั้งหมดไม่มีข้อความใน stderr; สองกรณีจงใจให้ compile ไม่ผ่านได้ exit code 1 พร้อม error เกี่ยวกับ Print และการแปลง StringLiteral เป็น Int ตามลำดับ

## สิ่งที่เปลี่ยนจาก 1.1.0

- อัปเดตแพ็กเกจ Mojo และ compiler เป็น 1.2.0 (2016d0cd) พร้อมบันทึก dependency ที่ติดตั้งจริงใน [ไฟล์ล็อก](../requirements-mojo-lock.txt)
- อัปเดตคู่มือติดตั้งและเวอร์ชันในบทเรียน EP.1–4 รวมถึงตัวตรวจที่ปฏิเสธ compiler คนละรุ่น
- โค้ดตัวอย่างและเฉลยเดิมทั้งสี่บทใช้กับ 1.2.0 ได้ จึงไม่ต้องแก้ไวยากรณ์หรือผลคาดหวังเพื่อให้ผ่านการทดสอบ
- คงขั้นคาดเดา → พิมพ์ → รัน → อธิบาย → ทดลองผิด → แก้กลับ พร้อมคำอธิบายสำหรับผู้เริ่มเรียน
- ผลตรวจนี้ไม่รับรองตัวอย่างขั้นสูงที่ยังไม่ได้เขียน ดู [แหล่งอ้างอิงและการกำหนดเวอร์ชัน](../docs/REFERENCES.md)

หลักฐานรุ่นเดิมวันที่ 5 ตุลาคม 2026 เก็บแยกไว้: [ผลรัน Mojo 1.1.0](history/mojo-1.1.0/validation-results.json) และ [dependency รุ่นเดิม](history/mojo-1.1.0/requirements-mojo-lock.txt)

## รันตรวจซ้ำ

เปิด Ubuntu-24.04 ที่โฟลเดอร์หลักสูตร:

~~~bash
cd /mnt/c/Users/kopes/Documents/L/MOJO
source .venv/bin/activate
python scripts/check_examples.py
~~~

สคริปต์จะทดสอบในโฟลเดอร์ชั่วคราวเมื่อจำเป็น และเขียนรายงานล่าสุดทับ notes/validation-results.json หากต้องการเก็บหลักฐานก่อนเปลี่ยนเวอร์ชันให้สำรองรายงานเดิมไว้ก่อน

## ขอบเขตของผลตรวจ

- ตรวจตัวอย่างใน examples, main และ solutions ของ EP.1–4 รวมเงื่อนไขขอบเขตที่ระบุ
- ตรวจผลลัพธ์ข้อความและการคอมไพล์ตามรุ่นที่ระบุ ไม่ใช่ benchmark
- ไม่ได้จงใจรัน while ที่ไม่หยุด การอธิบายกรณีนั้นใช้การไล่ค่าในเอกสาร
- ผลรอบนี้จำกัดที่ Ubuntu WSL2 และ Mojo 1.2.0 ไม่ได้ยืนยัน macOS หรือ Linux นอก WSL
- EP.5–48, Python interop, MAX และ GPU ยังเป็นแผนและยังไม่ได้ทดสอบ
- ตรวจลิงก์ไฟล์ภายในและ code fence ของเอกสาร ไม่พบลิงก์เสียหรือ fence ค้าง; ยังไม่ได้ตรวจหน้าตาบน GitHub หรือแพลตฟอร์มเผยแพร่จริง
- ไฟล์โค้ด 28 ไฟล์ของ EP.1–4 อยู่ในชุดตรวจครบ; โค้ดเต็มในหน้าบทเรียนและเฉลยตรงกับไฟล์ที่ทดสอบ
- เอกสารพร้อมให้ทดลองเรียน ผู้สอนควรทำโจทย์เองและตรวจความเข้าใจก่อนอัด
