# พื้นที่ฝึกเขียนโค้ด

ติดตั้ง Mojo ตาม [ขั้นตอนเริ่มต้นใน README](../README.md) และรันตัวอย่าง EP.1 ให้ได้ก่อน

เปิด Ubuntu WSL แล้วเข้าโฟลเดอร์ที่เก็บโค้ด

ถ้าใช้ตำแหน่งตัวอย่างตาม README ให้รัน:

~~~bash
cd /mnt/c/mojo-course/MOJO
~~~

หากเก็บโค้ดที่อื่น ให้เปลี่ยนเส้นทางให้ตรงกับเครื่องของตนเอง

เปิดใช้งาน environment:

~~~bash
source .venv/bin/activate
~~~

สร้างโฟลเดอร์ฝึก:

~~~bash
mkdir -p practice
~~~

ใช้ editor สร้างไฟล์:

~~~text
practice/main.mojo
~~~

พิมพ์โค้ดตามบทเรียน แล้วบันทึกไฟล์

รันจากโฟลเดอร์หลักสูตร:

~~~bash
mojo practice/main.mojo
~~~

ก่อนขึ้นบทใหม่ สามารถเก็บคำตอบเดิมด้วยชื่ออื่น เช่น:

~~~text
practice/ep01-my-answer.mojo
~~~

จากนั้นใช้ไฟล์หลักสำหรับฝึกบทใหม่

โฟลเดอร์ฝึกถูกยกเว้นใน .gitignore จึงไม่ปะปนกับโค้ดต้นฉบับเมื่อใช้ Git

โค้ดอ้างอิงของแต่ละตอนอยู่ใน:

~~~text
lessons/phase-01/
~~~

เปิดต้นฉบับเทียบได้โดยไม่ต้องแก้ไฟล์ตัวอย่าง

เมื่อเปิด terminal ใหม่ ต้องเข้าโฟลเดอร์หลักสูตรและเปิดใช้งาน environment อีกครั้ง
