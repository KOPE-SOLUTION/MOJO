# EP.4 ทำซ้ำด้วย for และ while

**เป้าหมาย:** เลือก for/while และกำหนดเงื่อนไขหยุดได้

**ก่อนเริ่ม:** เข้าใจการคำนวณและ if จาก EP.3

**รุ่นเป้าหมาย:** Mojo 1.2.0 · [ผลตรวจจริง](../../../notes/validation.md)

## ทำความเข้าใจ

**ลูป** คือการทำคำสั่งชุดเดิมซ้ำ

| คำสั่ง | การทำงาน |
|---|---|
| `for` | ไล่ค่าจากลำดับทีละค่า |
| `while` | ทำต่อขณะที่เงื่อนไขยังเป็นจริง |

เลือกชนิดของลูปให้เหมาะกับงาน และกำหนดให้ชัดว่าลูปจะหยุดเมื่อใด

## เตรียมพื้นที่ฝึก

สร้างไฟล์ตาม [คู่มือพื้นที่ฝึก](../../../docs/PRACTICE.md):

~~~text
practice/main.mojo
~~~

เปิด terminal ของ Ubuntu WSL ที่โฟลเดอร์หลักสูตร แล้วเปิดใช้งาน environment:

~~~bash
source .venv/bin/activate
~~~

ทำขั้นนี้ครั้งเดียวต่อ terminal

หลังพิมพ์และบันทึกโค้ดแต่ละขั้น ให้รันไฟล์ฝึกด้วยคำสั่งเดิม:

~~~bash
mojo practice/main.mojo
~~~

ตรวจว่าชื่อไฟล์ที่เปิดแก้ตรงกับชื่อไฟล์ที่สั่งรัน

## ลงมือทำทีละขั้น

### 1. รวมค่าจากลำดับด้วย for

แทนที่ไฟล์ด้วยโค้ดด้านล่าง

ช่วงที่ใช้ในลูปคือ:

~~~text
range(1, 5)
~~~

ได้ค่า 1, 2, 3 และ 4 โดยไม่รวมขอบท้ายคือ 5

ตัวแปร `total` เก็บผลสะสมหลังจบแต่ละรอบ

~~~mojo
def main():
    var total: Int = 0
    for value in range(1, 5):
        total = total + value
    print("Total:", total)
~~~

ขอบท้ายของ `range` ไม่รวมอยู่ในลำดับ

ในตัวอย่างนี้ ลูปจึงทำงาน 4 รอบ แล้วแสดงผลรวมหนึ่งครั้งหลังออกจากลูป

**ลองคิดก่อนรัน:**

มีทั้งหมดกี่รอบ และทำไมไม่รวมค่า 5?

<details>
<summary>รันแล้วค่อยเปิดตรวจผลที่คาดหวัง</summary>

~~~text
Total: 10
~~~

</details>

[ไฟล์อ้างอิงขั้นนี้](examples/step-1.mojo)

### 2. ทำต่อขณะเงื่อนไขจริงด้วย while

แทนที่ไฟล์ด้วยลูปนับถอยหลัง

ในแต่ละรอบ ลดค่า `remaining` ลงหนึ่ง เพื่อให้เงื่อนไขเปลี่ยนและจบลูปได้

~~~mojo
def main():
    var remaining: Int = 3
    while remaining > 0:
        print("Remaining:", remaining)
        remaining = remaining - 1
    print("Done")
~~~

ลูปตรวจเงื่อนไขก่อนเริ่มทำงานแต่ละรอบ

เมื่อค่าลดลงจนเป็น 0 เงื่อนไขจะเป็นเท็จ จึงออกจากลูป

จากนั้นจึงแสดงข้อความจบงาน:

~~~text
Done
~~~

**ลองคิดก่อนรัน:**

โปรแกรมจะแสดงบรรทัดนี้หรือไม่?

~~~text
Remaining: 0
~~~

ถ้าไม่ลดค่าตัวนับ จะเกิดอะไรขึ้น?

<details>
<summary>รันแล้วค่อยเปิดตรวจผลที่คาดหวัง</summary>

~~~text
Remaining: 3
Remaining: 2
Remaining: 1
Done
~~~

</details>

[ไฟล์อ้างอิงขั้นนี้](examples/step-2.mojo)

### 3. ข้ามรอบและหยุดด้วย continue/break

ใช้ตัวอย่างใหม่เพื่อเปรียบเทียบคำสั่งสองแบบ:

| คำสั่ง | ผลที่เกิดขึ้น |
|---|---|
| `continue` | ข้ามส่วนที่เหลือของรอบปัจจุบัน แล้วไปรอบถัดไป |
| `break` | ออกจากลูปทันที |

~~~mojo
def main():
    for value in range(1, 7):
        if value == 3:
            continue
        if value == 5:
            break
        print("Value:", value)
~~~

เมื่อค่าเป็น 3 จะข้ามคำสั่งแสดงผลในรอบนั้น

เมื่อค่าเป็น 5 จะหยุดลูปก่อนแสดงผล จึงไม่ถึงรอบที่ค่าเป็น 6

**ลองคิดก่อนรัน:**

ทำไมไม่มีทั้งค่า 3, 5 และ 6 ในผลลัพธ์?

<details>
<summary>รันแล้วค่อยเปิดตรวจผลที่คาดหวัง</summary>

~~~text
Value: 1
Value: 2
Value: 4
~~~

</details>

[ไฟล์อ้างอิงขั้นนี้](examples/step-3.mojo)

### 4. ทดลองทำให้ผิด แล้วแก้กลับ

โจทย์ยังต้องการรวมจำนวน 1 ถึง 4 แต่ลองเปลี่ยนขอบท้ายของช่วงเป็น:

~~~text
range(1, 4)
~~~

ลูปจะมีเพียงค่า 1, 2 และ 3 จึงได้ผลรวม 6

หลังทดลองแล้ว ให้แก้ขอบท้ายกลับเป็น 5 และรันจนได้ผลรวม 10

~~~mojo
def main():
    var total: Int = 0
    for value in range(1, 4):
        total = total + value
    print("Total:", total)
~~~

ดูโค้ดสำหรับทดลองผิดใน [ไฟล์ข้อความ](examples/intentional-error.mojo.txt)

คัดลอกไปแทนเนื้อหาในไฟล์ฝึก แล้วแก้กลับก่อนทำโจทย์

ผลผิดที่คาดว่าจะเห็นจากโค้ดนี้:

~~~text
Total: 6
~~~


กรณีลูปไม่หยุดเพราะลืมอัปเดตค่า ให้ลองไล่ค่าบนกระดาษก่อน

หากโปรแกรมค้างอยู่ในลูป สามารถหยุดการรันด้วย:

~~~text
Ctrl+C
~~~

### 5. รันตัวอย่างหลังแก้

กลับไปใช้โค้ดขั้นที่ 3 บันทึกไฟล์ แล้วรันอีกครั้ง

ผลควรตรงกับขั้นที่ 3

หากต้องการรันไฟล์ต้นฉบับ ให้ใช้คำสั่งนี้จากโฟลเดอร์หลักสูตร:

~~~bash
mojo lessons/phase-01/ep04-loops/main.mojo
~~~

## ฝึกเอง

### ข้อ 1 รวมจำนวน

ใช้ `for` รวมจำนวนตั้งแต่ 1 ถึง 5

ผลที่ต้องการ:

~~~text
Total: 15
~~~

### ข้อ 2 นับจำนวนครั้ง

ใช้ `while` และกำหนดค่าเริ่มต้นของ `attempt` เป็น 1

แสดงผลตามนี้ แล้วออกจากลูป:

~~~text
Attempt: 1
Attempt: 2
Attempt: 3
~~~

ทำก่อนแล้วค่อยเปิด [เฉลยและเหตุผล](solutions/README.md)
