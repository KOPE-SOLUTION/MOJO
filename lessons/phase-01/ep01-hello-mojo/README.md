# EP.1 เขียน รัน และแก้โปรแกรม Mojo แรก

**เป้าหมาย:** รันโปรแกรม อธิบาย main และแก้ชื่อฟังก์ชันผิดได้

**ก่อนเริ่ม:** เตรียม Ubuntu WSL และ Mojo 1.2.0 ตามคู่มือติดตั้งแล้ว

**รุ่นเป้าหมาย:** Mojo 1.2.0 · [ผลตรวจจริง](../../../notes/validation.md)

## ทำความเข้าใจ

**Terminal** คือหน้าต่างสำหรับพิมพ์คำสั่ง

**Compiler** คือเครื่องมือที่ตรวจและแปลโค้ดก่อนโปรแกรมทำงาน

โปรแกรมในบทนี้เริ่มทำงานที่ฟังก์ชัน `main` แล้วทำคำสั่งภายในจากบนลงล่าง

การย่อหน้าบอกว่าคำสั่งใดอยู่ในบล็อกเดียวกัน รูปแบบนี้คล้ายกับที่ใช้ใน Python

## เตรียมพื้นที่ฝึก

สร้างไฟล์ตาม [คู่มือพื้นที่ฝึก](../../../docs/PRACTICE.md):

~~~text
practice/main.mojo
~~~

เปิด terminal ของ Ubuntu WSL ที่โฟลเดอร์หลักสูตร แล้วเปิดใช้งาน environment:

~~~bash
source .venv/bin/activate
~~~

ทำขั้นนี้ครั้งเดียวต่อ terminal

หลังพิมพ์และบันทึกโค้ดแต่ละขั้น ให้รันไฟล์ฝึกด้วยคำสั่งเดิม:

~~~bash
mojo practice/main.mojo
~~~

ตรวจว่าชื่อไฟล์ที่เปิดแก้ตรงกับชื่อไฟล์ที่สั่งรัน

## ลงมือทำทีละขั้น

### 1. เริ่มจากข้อความเดียว

แทนที่เนื้อหาในไฟล์ฝึกด้วยโค้ดทั้งหมดด้านล่าง

เว้นช่องว่าง 4 ตัวหน้าคำสั่ง `print` จากนั้นบันทึกไฟล์

~~~mojo
def main():
    print("Hello, Mojo!")
~~~

ข้อความในเครื่องหมายคำพูดคือข้อความที่เขียนไว้โดยตรงในโค้ด เรียกว่า **string literal**

คำสั่ง `print` แสดงข้อความนั้น แล้วขึ้นบรรทัดใหม่

ข้อความที่ส่งให้แสดงคือ:

~~~text
Hello, Mojo!
~~~

**ลองคิดก่อนรัน:**

เครื่องหมายคำพูดจะถูกพิมพ์ด้วยหรือไม่?

<details>
<summary>รันแล้วค่อยเปิดตรวจผลที่คาดหวัง</summary>

~~~text
Hello, Mojo!
~~~

</details>

[ไฟล์อ้างอิงขั้นนี้](examples/step-1.mojo)

### 2. เพิ่มชื่อชุดข้อมูล

แทนที่เนื้อหาไฟล์ด้วยโค้ดนี้

เพิ่มคำสั่งใหม่หนึ่งบรรทัดภายในฟังก์ชัน `main`

~~~mojo
def main():
    print("Hello, Mojo!")
    print("Dataset: demo-01")
~~~

ทั้งสองคำสั่งอยู่ในบล็อกเดียวกัน จึงทำตามลำดับจากบนลงล่าง

บรรทัดใหม่แสดงชื่อชุดข้อมูลที่เราพิมพ์ไว้:

~~~text
Dataset: demo-01
~~~

ขั้นนี้เป็นการแสดงข้อความ ยังไม่มีการเปิดหรือโหลดชุดข้อมูล

**ลองคิดก่อนรัน:**

ข้อความใดจะออกก่อน และมีกี่บรรทัด?

<details>
<summary>รันแล้วค่อยเปิดตรวจผลที่คาดหวัง</summary>

~~~text
Hello, Mojo!
Dataset: demo-01
~~~

</details>

[ไฟล์อ้างอิงขั้นนี้](examples/step-2.mojo)

### 3. เพิ่มสถานะพร้อมทำงาน

เพิ่มข้อความสถานะท้ายบล็อก จากนี้คือโค้ดฉบับจบของบท

~~~mojo
def main():
    print("Hello, Mojo!")
    print("Dataset: demo-01")
    print("Status: ready")
~~~

สถานะในตัวอย่างเป็นข้อความคงที่ที่เราพิมพ์ไว้:

~~~text
Status: ready
~~~

โปรแกรมยังไม่ได้ตรวจความพร้อมของระบบ

บทนี้ฝึกลำดับการแสดงข้อความ ส่วนบทถัดไปจะเริ่มเก็บค่าในตัวแปร

**ลองคิดก่อนรัน:**

ถ้าสลับ print บรรทัดสองกับสาม ผลลัพธ์จะสลับตามหรือไม่?

<details>
<summary>รันแล้วค่อยเปิดตรวจผลที่คาดหวัง</summary>

~~~text
Hello, Mojo!
Dataset: demo-01
Status: ready
~~~

</details>

[ไฟล์อ้างอิงขั้นนี้](examples/step-3.mojo)

### 4. ทดลองทำให้ผิด แล้วแก้กลับ

แทนที่ไฟล์ฝึกด้วยโค้ดสั้นด้านล่าง แล้วบันทึกและรัน

ตัวอย่างนี้ใช้ชื่อฟังก์ชันที่ขึ้นต้นด้วยตัวพิมพ์ใหญ่:

~~~text
Print
~~~

ชื่อนี้ไม่ได้ประกาศไว้ โปรแกรมจึงควรคอมไพล์ไม่ผ่าน

~~~mojo
def main():
    Print("Hello, Mojo!")
~~~

ดูโค้ดสำหรับทดลองผิดใน [ไฟล์ข้อความ](examples/intentional-error.mojo.txt)

อ่านชื่อไฟล์ ตำแหน่ง และชื่อฟังก์ชันที่ระบุในข้อความผิดพลาด

แก้ชื่อให้ขึ้นต้นด้วยตัวพิมพ์เล็ก:

~~~text
print
~~~

บันทึกแล้วรันใหม่ จากนั้นคืนโค้ดเต็มตามขั้นที่ 3

ไม่ต้องจำข้อความผิดพลาดทั้งประโยค ให้เข้าใจสาเหตุเป็นหลัก


### 5. รันตัวอย่างหลังแก้

กลับไปใช้โค้ดขั้นที่ 3 บันทึกไฟล์ แล้วรันอีกครั้ง

ผลควรตรงกับขั้นที่ 3

หากต้องการรันไฟล์ต้นฉบับ ให้ใช้คำสั่งนี้จากโฟลเดอร์หลักสูตร:

~~~bash
mojo lessons/phase-01/ep01-hello-mojo/main.mojo
~~~

[โค้ดฉบับจบบท](main.mojo)

## ฝึกเอง

### ข้อ 1 เปลี่ยนข้อความ

เปลี่ยนชื่อชุดข้อมูลและสถานะ ให้แสดงผลครบ 3 บรรทัดดังนี้:

~~~text
Hello, Mojo!
Dataset: demo-02
Status: waiting
~~~

### ข้อ 2 เพิ่มข้อความท้ายโปรแกรม

เริ่มจากโค้ดขั้นที่ 3 แล้วเพิ่มข้อความต่อท้าย:

~~~text
Author: learner
~~~

คาดเดาจำนวนบรรทัดทั้งหมดก่อนรัน

ทำก่อนแล้วค่อยเปิด [เฉลยและเหตุผล](solutions/README.md)

## ตรวจความเข้าใจ

**ลองอธิบาย:**

ทำไมเพียงบันทึกไฟล์แล้วจึงยังไม่เห็นข้อความใน terminal?

<details>
<summary>แนวคำตอบ</summary>

การบันทึกเปลี่ยนไฟล์บนดิสก์ ต้องสั่งรันไฟล์นั้นจึงเกิดการแปลและเรียก main

</details>

**ผ่านบทนี้เมื่อ:**

เขียนโปรแกรมที่แสดงข้อความ 3 บรรทัดได้ด้วยตนเอง

รันโปรแกรมจาก terminal และอธิบายได้ว่าตัวพิมพ์ใหญ่กับตัวพิมพ์เล็กมีผลต่อชื่อฟังก์ชันอย่างไร

**นำไปต่อ:**

ตัวแปรและชนิดข้อมูล

## เมื่อรันไม่ได้

4. ย่อหน้าให้สม่ำเสมอ
5. ใช้ Mojo 1.2.0 ตามบทเรียน
