# EP.3 คำนวณและตรวจเงื่อนไขของข้อมูล

**เป้าหมาย:** อ่านลำดับคำนวณและเลือกเงื่อนไขที่รวมค่าขอบเขตถูกต้อง

**ก่อนเริ่ม:** เข้าใจ var และ Int จาก EP.2

**รุ่นเป้าหมาย:** Mojo 1.2.0 · [ผลตรวจจริง](../../../notes/validation.md)

## ทำความเข้าใจ

ตัวดำเนินการใช้คำนวณหรือเปรียบเทียบค่า

| เครื่องหมาย | ความหมาย |
|---|---|
| `+` | บวก |
| `>=` | มากกว่าหรือเท่ากับ |

ผลเปรียบเทียบเป็นจริงหรือเท็จ แล้วนำไปใช้เลือกทางทำงานด้วย `if`

โจทย์นี้กำหนดให้อุณหภูมิตั้งแต่ 30 ขึ้นไปแสดงสถานะเตือน:

~~~text
WARNING
~~~

## เตรียมพื้นที่ฝึก

สร้างไฟล์ตาม [คู่มือพื้นที่ฝึก](../../../docs/PRACTICE.md):

~~~text
practice/main.mojo
~~~

เปิด terminal ของ Ubuntu WSL ที่โฟลเดอร์หลักสูตร แล้วเปิดใช้งาน environment:

~~~bash
source .venv/bin/activate
~~~

หลังพิมพ์และบันทึกโค้ดแต่ละขั้น ให้รันไฟล์ฝึกด้วยคำสั่งเดิม:

~~~bash
mojo practice/main.mojo
~~~

ตรวจว่าชื่อไฟล์ที่เปิดแก้ตรงกับชื่อไฟล์ที่สั่งรัน

## ลงมือทำทีละขั้น

### 1. คำนวณด้วยวงเล็บ

แทนที่เนื้อหาไฟล์ด้วยตัวอย่างนี้

เปรียบเทียบการคูณก่อนบวกกับการใช้วงเล็บ

~~~mojo
def main():
    var first: Int = 2 + 3 * 4
    var second: Int = (2 + 3) * 4
    print("First:", first)
    print("Second:", second)
~~~

แบบแรกคูณ 3 กับ 4 ก่อน แล้วจึงบวก 2

แบบที่สองบวก 2 กับ 3 ในวงเล็บก่อน แล้วจึงคูณ 4

**ลองคิดก่อนรัน:**

สองนิพจน์ที่ใช้ตัวเลขเหมือนกันจะได้คำตอบเท่ากันหรือไม่?

<details>
<summary>รันแล้วค่อยเปิดตรวจผลที่คาดหวัง</summary>

~~~text
First: 14
Second: 20
~~~

</details>

[ไฟล์อ้างอิงขั้นนี้](examples/step-1.mojo)

### 2. ตรวจค่าที่เท่ากับเกณฑ์

แทนที่ไฟล์ด้วยโค้ดนี้

ใช้เครื่องหมาย `>=` เพื่อรวมกรณีที่ค่าเท่ากับ 30

ชุดเงื่อนไข `if` และ `else` เลือกทำเพียงทางเดียว

~~~mojo
def main():
    var temperature: Int = 30
    var threshold: Int = 30
    print("Temperature:", temperature)
    if temperature >= threshold:
        print("Status: WARNING")
    else:
        print("Status: OK")
~~~

ค่าเท่ากับเกณฑ์ต้องเตือนตามกฎของโจทย์ จึงใช้เครื่องหมาย `>=`

การคอมไพล์ผ่านยืนยันว่าเขียนโค้ดได้ถูกหลักภาษา แต่ยังต้องตรวจว่าผลตรงกับกฎของโจทย์หรือไม่

**ลองคิดก่อนรัน:**

ถ้าเปลี่ยน >= เป็น > ที่ค่า 30 ผลจะเหมือนเดิมหรือไม่?

<summary>รันแล้วค่อยเปิดตรวจผลที่คาดหวัง</summary>

~~~text

Status: WARNING
~~~

</details>

### 3. เพิ่มช่วงค่าที่ใช้ไม่ได้

เพิ่มเงื่อนไขแรกสำหรับค่าติดลบ แล้วใช้ `elif` ตรวจข้อมูลที่เหลือ

ในโจทย์สมมตินี้ ค่าติดลบถือว่าใช้ไม่ได้ และให้แสดงสถานะ:

~~~text
INVALID
~~~

นี่เป็นกฎของแบบฝึกหัด อุณหภูมิจริงสามารถติดลบได้

~~~mojo
def main():
    var temperature: Int = 30
    var threshold: Int = 30
    print("Temperature:", temperature)
    if temperature < 0:
        print("Status: INVALID")
    elif temperature >= threshold:
        print("Status: WARNING")
    else:
        print("Status: OK")
~~~

คำสั่ง `if`, `elif` และ `else` ในตัวอย่างเป็นชุดทางเลือกเดียวกัน

ตรวจจากบนลงล่าง เมื่อเข้าเงื่อนไขใดแล้ว จะไม่ทำทางเลือกอื่นในชุดเดียวกัน

**ลองคิดก่อนรัน:**

ถ้าอุณหภูมิเป็น -1 โปรแกรมจะเลือกเพียงสถานะเดียว หรือแสดงสถานะอื่นต่อด้วย?

<details>
<summary>รันแล้วค่อยเปิดตรวจผลที่คาดหวัง</summary>

~~~text
Temperature: 30
Status: WARNING
~~~

</details>

### 4. ทดลองทำให้ผิด แล้วแก้กลับ

ลองโค้ดที่ใช้เครื่องหมาย `>` แทน `>=`

โปรแกรมรันได้ แต่เมื่อค่าเท่ากับ 30 กลับแสดงสถานะ:

~~~text
OK
~~~

ผลนี้ผิดจากกฎของโจทย์ เรียกว่า **ข้อผิดพลาดทางตรรกะ**

ทดลองค่า 29, 30 และ 31 ทีละค่า แล้วแก้เงื่อนไขกลับเป็น `>=`

~~~mojo
def main():
    var temperature: Int = 30
    var threshold: Int = 30
    if temperature > threshold:
        print("Status: WARNING")
    else:
        print("Status: OK")
~~~

ดูโค้ดสำหรับทดลองผิดใน [ไฟล์ข้อความ](examples/intentional-error.mojo.txt)

คัดลอกไปแทนเนื้อหาในไฟล์ฝึก แล้วแก้กลับก่อนทำโจทย์

ผลผิดที่คาดว่าจะเห็นจากโค้ดนี้:

~~~text
Status: OK
~~~

## ฝึกเอง

### ข้อ 1 ตรวจค่าขอบเขต

ใช้โค้ดขั้นที่ 3 แล้วเปลี่ยนอุณหภูมิทีละค่า:

~~~text
-1, 0, 29, 30, 31
~~~

เขียนตารางผลที่คาดไว้ก่อนรันแต่ละกรณี

### ข้อ 2 เปลี่ยนเกณฑ์

ตั้งตัวแปรเกณฑ์ `threshold` เป็น 35

ตั้งตัวแปรอุณหภูมิ `temperature` เป็น 35 เช่นกัน

ค่าเท่ากับเกณฑ์ยังต้องแสดงสถานะ:

~~~text
Status: WARNING
~~~

ทำก่อนแล้วค่อยเปิด [เฉลยและเหตุผล](solutions/README.md)

## ตรวจความเข้าใจ

**ลองอธิบาย:**

เหตุใดลองเพียงค่า 29 กับ 31 จึงยังจับข้อผิดพลาด > แทน >= ไม่ได้?

<details>
<summary>แนวคำตอบ</summary>

ที่ค่า 29 และ 31 ทั้งสองเงื่อนไขให้คำตอบเหมือนกัน

ต้องทดสอบค่าเท่ากับ 30 จึงจะเห็นความต่าง

</details>

**ผ่านบทนี้เมื่อ:**

เขียนเงื่อนไขจากประโยคภาษาไทยและเลือกค่าทดสอบต่ำกว่า/เท่ากับ/สูงกว่าเกณฑ์ได้

**นำไปต่อ:**

วนซ้ำด้วย for และ while
