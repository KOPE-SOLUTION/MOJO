# EP.2 เก็บข้อมูลด้วยตัวแปรและชนิดข้อมูล

**เป้าหมาย:** ประกาศตัวแปร เปลี่ยนค่า และอธิบาย type mismatch ได้

**ก่อนเริ่ม:** ผ่าน EP.1 และรัน practice/main.mojo ได้

**รุ่นเป้าหมาย:** Mojo 1.2.0 · [ผลตรวจจริง](../../../notes/validation.md)

## ทำความเข้าใจ

**ตัวแปร** เป็นชื่อที่ใช้เข้าถึงค่า

**ชนิดข้อมูล** กำหนดว่าค่านั้นใช้แบบใดได้

Mojo ตรวจชนิดข้อมูลขณะคอมไพล์ แม้บางครั้งเราไม่ได้เขียนชื่อชนิดเอง

การเปลี่ยนค่าจึงต้องใช้ชนิดที่เข้ากันได้ ต่างจาก Python ที่ผูกชื่อเดิมกับวัตถุคนละชนิดได้

## เตรียมพื้นที่ฝึก

สร้างไฟล์ตาม [คู่มือพื้นที่ฝึก](../../../docs/PRACTICE.md):

~~~text
practice/main.mojo
~~~

เปิด terminal ของ Ubuntu WSL ที่โฟลเดอร์หลักสูตร แล้วเปิดใช้งาน environment:

~~~bash
source .venv/bin/activate
~~~

ทำขั้นนี้ครั้งเดียวต่อ terminal

หลังพิมพ์และบันทึกโค้ดแต่ละขั้น ให้รันไฟล์ฝึกด้วยคำสั่งเดิม:

~~~bash
mojo practice/main.mojo
~~~

ตรวจว่าชื่อไฟล์ที่เปิดแก้ตรงกับชื่อไฟล์ที่สั่งรัน

## ลงมือทำทีละขั้น

### 1. ตั้งชื่อให้ค่าจำนวนเต็ม

แทนที่เนื้อหาไฟล์ฝึกทั้งหมดด้วยโค้ดนี้

ใช้ `var` ประกาศตัวแปร

ส่วน `: Int` ระบุว่าตัวแปรเก็บจำนวนเต็ม

~~~mojo
def main():
    var sample_count: Int = 3
    print("Samples:", sample_count)
~~~

ชื่อ `sample_count` ไม่มีเครื่องหมายคำพูด จึงเป็นการอ่านค่าจากตัวแปร

ส่วนข้อความในเครื่องหมายคำพูดเป็นป้ายกำกับ:

~~~text
Samples:
~~~

**ลองคิดก่อนรัน:**

print จะแสดงชื่อ sample_count หรือค่าที่เก็บอยู่?

<details>
<summary>รันแล้วค่อยเปิดตรวจผลที่คาดหวัง</summary>

~~~text
Samples: 3
~~~

</details>

[ไฟล์อ้างอิงขั้นนี้](examples/step-1.mojo)

### 2. เปลี่ยนค่าก่อนใช้อีกครั้ง

เพิ่มการกำหนดค่าใหม่หลังการแสดงผลครั้งแรก

การเขียนชื่อเดิมโดยไม่มี `var` คือการอัปเดตค่าของตัวแปรเดิม

~~~mojo
def main():
    var sample_count: Int = 3
    print("Before:", sample_count)
    sample_count = 5
    print("After:", sample_count)
~~~

การแสดงผลครั้งแรกอ่านค่าที่มีอยู่ในขณะนั้น

การกำหนดค่าใหม่มีผลกับการอ่านครั้งถัดไป ไม่ย้อนกลับไปเปลี่ยนข้อความที่แสดงแล้ว

**ลองคิดก่อนรัน:**

print ครั้งแรกจะเปลี่ยนเป็น 5 ตามไปด้วยหรือไม่?

<details>
<summary>รันแล้วค่อยเปิดตรวจผลที่คาดหวัง</summary>

~~~text
Before: 3
After: 5
~~~

</details>

[ไฟล์อ้างอิงขั้นนี้](examples/step-2.mojo)

### 3. เพิ่มชื่อและค่าทศนิยม

แทนที่ไฟล์ด้วยตัวอย่างเต็มด้านล่าง

ชนิดข้อมูลที่ใช้ในขั้นนี้:

| ชนิด | ใช้เก็บข้อมูล |
|---|---|
| `String` | ข้อความ |
| `Float64` | เลขทศนิยมแบบ floating point |

ตัวแปร `sample_count` ไม่เขียนชื่อชนิดไว้ ให้ compiler อนุมานจากค่าเริ่มต้น

~~~mojo
def main():
    var dataset: String = "demo-01"
    var sample_count = 3
    var temperature: Float64 = 28.5
    print("Dataset:", dataset)
    print("Samples:", sample_count)
    print("Temperature:", temperature)
~~~

การอนุมานชนิดยังเป็นการกำหนดชนิดขณะคอมไพล์ หรือ **static typing**

compiler เลือกชนิดจากค่าเริ่มต้น ไม่ได้เปลี่ยนชนิดทุกครั้งที่กำหนดค่าใหม่

**ลองคิดก่อนรัน:**

เมื่อไม่ได้เขียน : Int ให้ sample_count แปลว่าสามารถเปลี่ยนเป็นข้อความภายหลังหรือไม่?

<details>
<summary>รันแล้วค่อยเปิดตรวจผลที่คาดหวัง</summary>

~~~text
Dataset: demo-01
Samples: 3
Temperature: 28.5
~~~

</details>

[ไฟล์อ้างอิงขั้นนี้](examples/step-3.mojo)

### 4. ทดลองทำให้ผิด แล้วแก้กลับ

ตัวแปรในตัวอย่างนี้ประกาศเป็นจำนวนเต็ม แต่บรรทัดถัดมาพยายามกำหนดข้อความให้:

~~~text
three
~~~

บันทึกแล้วรัน โปรแกรมควรคอมไพล์ไม่ผ่าน

~~~mojo
def main():
    var sample_count: Int = 3
    print(sample_count)
    sample_count = "three"
    print(sample_count)
~~~

ดูโค้ดสำหรับทดลองผิดใน [ไฟล์ข้อความ](examples/intentional-error.mojo.txt)

มองหาคำอธิบายว่าข้อความแปลงเป็นชนิด `Int` โดยอัตโนมัติไม่ได้

แก้บรรทัดที่ผิดให้กำหนดจำนวนเต็ม:

~~~text
sample_count = 5
~~~

บันทึกแล้วรันอีกครั้ง

แม้มีคำสั่งแสดงผลอยู่ก่อนบรรทัดที่ผิด โปรแกรมทั้งไฟล์ก็ยังคอมไพล์ไม่ผ่าน จึงยังไม่เริ่มทำงาน


### 5. รันตัวอย่างหลังแก้

กลับไปใช้โค้ดขั้นที่ 3 บันทึกไฟล์ แล้วรันอีกครั้ง

ผลควรตรงกับขั้นที่ 3

หากต้องการรันไฟล์ต้นฉบับ ให้ใช้คำสั่งนี้จากโฟลเดอร์หลักสูตร:

~~~bash
mojo lessons/phase-01/ep02-variables-types/main.mojo
~~~

## ฝึกเอง

### ข้อ 1 เปลี่ยนค่าจำนวนเต็ม

กำหนดค่าเริ่มต้นของ `sample_count` เป็น 10

แสดงค่าก่อนเปลี่ยน จากนั้นเพิ่มอีก 2 แล้วแสดงค่าใหม่

ผลที่ต้องการ:

~~~text
Before: 10
After: 12
~~~

### ข้อ 2 เลือกชนิดข้อมูล

ใช้ตัวแปรชนิด `String` เก็บชื่อชุดข้อมูล และ `Float64` เก็บอุณหภูมิ

แสดงผลสองบรรทัดดังนี้:

~~~text
Dataset: demo-02
Temperature: 30.5
~~~

ทำก่อนแล้วค่อยเปิด [เฉลยและเหตุผล](solutions/README.md)

## ตรวจความเข้าใจ

**ลองอธิบาย:**

การประกาศตัวแปรสองแบบนี้ต่างกันอย่างไร?

แบบที่ 1:

~~~text
var count = 3
~~~

แบบที่ 2:

~~~text
var count: Int = 3
~~~

<details>
<summary>แนวคำตอบ</summary>

แบบแรกให้ compiler อนุมานชนิด

แบบที่สองระบุชนิด `Int` ชัดเจน

ทั้งสองแบบไม่ได้อนุญาตให้เปลี่ยนตัวแปรนี้ไปเก็บข้อความ

</details>

**ผ่านบทนี้เมื่อ:**

เลือก String/Int/Float64 สำหรับข้อมูลตัวอย่างได้ และแก้ type mismatch โดยอธิบายเหตุผล

**นำไปต่อ:**

การคำนวณและการตรวจเงื่อนไข
